# Legacy Kenney Animal Heads — Not Used In Game

These PNG files are from the original Kenney Animal Pack Redux.

They are **not** the current player/customer art. They are cropped animal-head
illustrations and were kept only as a reference/download archive.

## Current animal art

The current full-body animals are drawn by code in:

`src/entities/CuteAnimals.js`

That file gives every animal the same cartoon style plus idle breathing,
blinking, and walking movement. Their sizes, colors, personalities, recipes,
and likes/dislikes are in:

`src/data/species.js`

## Preview the current animals

Start the local server, then open:

`http://localhost:8000/showcase.html`

The gallery renders every *actual current* animal, including bear, red
squirrel, moose, crocodile, elephant, frog, and all other customer types.
