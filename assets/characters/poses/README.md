# Character sit poses

Optional seated sprites used when a customer is `waiting` or `eating` at a table.

## Naming

Place files here as:

```
assets/characters/poses/<species_id>_sit.png
```

Examples: `bunny_sit.png`, `red_panda_sit.png`, `bear_sit.png`.

Keys are registered in `ASSET_MANIFEST.images`. Missing files soft-fail and fall back to direction / standing sprites.
