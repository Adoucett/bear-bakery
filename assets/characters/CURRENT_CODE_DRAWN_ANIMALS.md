# Current Full-Body Animal Art

Active character art is **local PNG sprites** in `assets/characters/current/`.

| What you want to edit | File |
|---|---|
| Replace / tweak a character image | `assets/characters/current/<id>.png` |
| Baker Bear cosmetics | `bear_hat.png`, `bear_glasses.png`, `bear_hat_glasses.png` |
| Animal size, personality, likes/dislikes, order pool | `src/data/species.js` |
| Dialogue lines | `src/data/dialogue.js` |
| How sprites are drawn (scale, bob, facing) | `src/entities/CharacterArt.js` |

Open `showcase.html` through the local server to preview every animal.
