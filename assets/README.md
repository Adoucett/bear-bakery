# Bear Bakery Assets

## Characters — local PNG sprites (realistic-cute)

All bakery animals are full-body PNGs in:

`assets/characters/current/<species>.png`

Drawn in-game via `src/entities/CharacterArt.js` (breath / walk micro-animation).
Procedural `CuteAnimals.js` remains only as a fallback if a sprite fails to load.

Legacy Kenney head PNGs remain in `sprites/animals/` (CC0) unused.

Style reference: `assets/characters/style-sheet.png`

Baker Bear unlockable looks: `bear_hat.png`, `bear_glasses.png`, `bear_hat_glasses.png`
(buy in the Back Office shop).

For a live preview of every animal, recipe, dialogue sample, and music
track, open:

`http://localhost:8000/showcase.html`

For a file-by-file explanation, see:

`docs/FILE_GUIDE.md`
